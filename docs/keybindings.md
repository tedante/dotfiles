# Keybindings

## Desktop Shortcuts

| Action                 | Shortcut                           |
| ---------------------- | ---------------------------------- |
| **Open Terminal**      | `Super + Return`                   |
| **Close Window**       | `Super + Q`                        |
| **Search (Ulauncher)** | `Ctrl + Space`                     |
| **File Manager**       | `Super + Shift + F` or `Super + E` |
| **Switch Workspace**   | `Super + 1, 2, 3, 4`               |
| **Screenshot (Area)**  | `Super + Shift + S`                |

Additional shortcuts that cannot be set by script are listed in [Configuration](configuration.md#manual-steps-required).

## Vim

### Cursor Movement

```text
h - left
j - down
k - up
l - right
H - top of screen
M - middle of screen
L - bottom of screen
w - start of next word
e - end of next word
```

### Insert Mode

```text
i - insert before cursor
I - insert at beginning of line
```

### Windows

```text
Ctrl + ws - split window
Ctrl + wv - vertical split
Ctrl + ww - switch between windows
Ctrl + wq - quit window
Ctrl + wx - exchange with next window
Ctrl + w= - equalize window sizes
Ctrl + wh - move cursor to window left
Ctrl + wl - move cursor to window right
```

### Cut and Paste

```text
yy  - yank (copy) one line
2yy - yank two lines
p   - paste after cursor
dd  - delete (cut) a line
x   - delete a character
```
